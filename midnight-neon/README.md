# Midnight Neon

Claude-Code-Theme (Mod) mit automatischem Hell/Dunkel-Modus.

- Hell: schlicht, kontrastreich, strahlend (Blau-Akzent)
- Dunkel: Mitternachtsblau/-lila mit Neon-Komplementärakzenten (Orange, Grün, Violett)

Zeichnen nur Desktop- und Mobile-Client, nicht das Terminal.

## Dateien
- `hooks/register.tsx`: das Theme
- `previews/theme-vorschau.html`: Farbvorschau hell/dunkel
- `previews/fliessband-entwurf.html`: Entwurf für ein aktives Design (Orchestrator, Fable, Sonnet, Opus am Fließband). Noch nicht Teil des Themes.

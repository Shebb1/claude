# app-compliance-kit

Claude-Code-Plugin mit dem Skill `/app-compliance`: rüstet bestehende Web-Apps für den Launch rechtlich und sicherheitstechnisch auf.

Installation: `/plugin marketplace add Shebb1/claude` → `/plugin install app-compliance-kit@shebb1-claude`
Start: `/app-compliance` (optional: Modulnummer, `alle`, `status`)

Ablauf: Projekt-Scan → Auswahlmenü (15 Module) → vorbefüllter Fragebogen → Plan → Umsetzung → Verifikation. Gemeinsamer Speicher: `.compliance/profile.json` im Zielprojekt.
Alle Rechtstexte sind Entwürfe, keine Rechtsberatung.
